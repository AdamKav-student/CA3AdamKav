# CA 3 MDP Armoured Warfare -

This is my submission for CA 3 (SINCE RESUBMITTED) Adam Kavanagh 

The game is based of of the in class example of Robo cat developed into an altered version featuring tanks 
Currently the game allows game mode is a free for all deathmatch with the first player to reach 10 kill becoming the winner then the game suits down shortly after 

Main menu provides only two option which is to load into the game or view the setting for the game 

Controls (Gameplay)
- Classic WASD movement for the tanks chassis (body)
- Arrow keys for turret rotation 
- Enter and Space are used to Fire the cannon (Short delay between firing)

Controls (Quality of life)
- M will toggle mute your game (Not shown in contols)
- Holding Tab will display additional server and game information
